# VOID Downloads

Dieses Repository enthält ausschließlich fertige VOID-Installer, öffentliche Update-Signaturen, Update-Manifeste und Changelogs.

Der VOID-Quellcode und private Signierschlüssel werden hier nicht veröffentlicht.

## Downloads

Freigegebene Versionen erscheinen unter [Releases](https://github.com/saturex/void-releases/releases). Aktuell ist noch keine Version zum Download freigegeben.

## Status

Die erste Beta und die automatische Update-Anbindung werden vorbereitet. Dieses Repository stellt keine öffentliche VOID-Account- oder Cape-API bereit.

Die Nutzungsbedingungen werden vor der ersten Veröffentlichung zusammen mit den erforderlichen Hinweisen zu Drittanbieter-Komponenten bereitgestellt.
